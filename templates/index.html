¿Cómo funciona?

      


        

          01
          
Frontend — JavaScript

          
El usuario selecciona una figura e ingresa medidas. JavaScript construye un objeto JSON y lo envía al servidor vía fetch API.

          fetch('/calcular', { method: 'POST' })
        


        
→


        

          02
          
Backend — Python Flask

          
Flask recibe el request, instancia la clase correspondiente y ejecuta los métodos de cálculo con precisión matemática.

          Circulo(radio).info()
        


        
→


        

          03
          
Response — JSON API

          
Python retorna los resultados en formato JSON. JavaScript los recibe y actualiza la interfaz dinámicamente.

          jsonify(resultado)
