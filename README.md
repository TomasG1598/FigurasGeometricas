# GeoCalc — Calculadora de Figuras Geométricas

Aplicación web fullstack con backend en Python/Flask y frontend en HTML, CSS y JavaScript. Calcula área, perímetro y volumen de figuras 2D y 3D a través de una API REST.

## 🌐 Demo en vivo
https://figurasgeometricas.onrender.com

## ⚙️ Stack técnico
- **Backend:** Python 3.13 + Flask 3.1
- **API:** REST — comunicación JSON entre frontend y backend
- **Frontend:** HTML5 · CSS3 · JavaScript ES6
- **Deploy:** Render.com

## 📐 Figuras disponibles
Círculo · Rectángulo · Triángulo · Hexágono · Cilindro · Esfera

## 🧠 Arquitectura
El frontend envía un POST request con los datos al servidor Flask.
Python instancia la clase correspondiente, ejecuta los cálculos
y retorna un JSON con área, perímetro, volumen y fórmulas aplicadas.
